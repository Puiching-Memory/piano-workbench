# README 图片来源

主 README 使用仓库内相对路径引用图片，不依赖临时图片链接。

| 文件 | 来源与用途 |
| --- | --- |
| `readme-hero.png` | 2026-10-29 使用内置 imagegen 生成的项目概念封面。钢琴、波形和谱面为示意，不是软件界面、音频测量或模型输出证据。完整提示词见 `hero-prompt.txt`。 |
