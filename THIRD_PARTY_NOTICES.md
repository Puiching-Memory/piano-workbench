# Third-party components and assets

Piano Workbench orchestrates upstream software. No upstream model weights, SoundFont samples, DAW binaries or commercial recordings are bundled.

| Component | Use | Source / licensing information |
| --- | --- | --- |
| DuET | Audio/performance-MIDI to structured score | https://github.com/wei-zeng98/DuET — code MIT; epoch83 weights **CC BY-NC 4.0**, separate from code |
| Transkun | Independent audio frontend called by DuET | https://github.com/Yujia-Yan/Transkun — consult upstream license and packaged checkpoint notices |
| TinySoundFont / tinysoundfont | SF2 rendering | https://github.com/schellingb/TinySoundFont ; https://pypi.org/project/tinysoundfont/ |
| mido / NumPy | MIDI parsing and audio arrays | https://mido.readthedocs.io/ ; https://numpy.org/ |
| FFmpeg | Decode, loudness measurement, constant gain, export | https://ffmpeg.org/legal.html — licensing depends on the installed build; not bundled |
| music21 / Verovio | Optional notation and engraving | https://www.music21.org/ ; https://www.verovio.org/ |
| svglib / ReportLab | Optional SVG-to-PDF composition | https://github.com/deeplook/svglib ; https://www.reportlab.com/ |
| FL Studio / FLEX | Optional external/manual DAW workflow | https://www.image-line.com/ — commercial software and content; not bundled |

Installation downloads dependencies from their own sources and retains their distributed license files. Installing this MIT package does not relicense any dependency or model.

## Example media

`examples/original-eight-bars/` contains an original synthetic MIDI/MusicXML composition generated by this project's `demo` command. It is not a transcription of a third-party song and is MIT licensed as part of this project.

If rendered sample audio is supplied, see `examples/listening/ATTRIBUTION.md` for the exact instrument, license and generation procedure. The audio's sound-source rights are not represented as covered by the project's code license.

For your own runs, record SF2 author, source URL and license alongside the generated outputs. Users supply their own audio, model access and instrument files. Model/input/output permissions must be assessed independently before publishing or commercial deployment.
